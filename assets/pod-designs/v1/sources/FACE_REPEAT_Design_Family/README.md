# DigiForge FACE_REPEAT — design prototypes v1

Eight independently authored SVG layout prototypes. Face graphics are stylized vector placeholders, **not customer-photo cutouts**, and do not demonstrate a production face-isolation engine. SVG uses live placeholder text for FR07; replace using licensed fonts and the canonical renderer.

## Intended pipeline
1. Customer supplies an image with rights/consent; validate file and shop ownership.
2. Isolate subject with approved segmentation engine; retain original and mask provenance.
3. Substitute subject assets in a versioned FACE_REPEAT template and compose a repeat tile.
4. Bind exact Printify blueprint, provider, variant, placement and authoritative geometry.
5. Verify safe zones, seams, heel/toe/wrap, scaling, DPI and preview/final parity.
6. Freeze approvals and require operational authorization before provider actions.

## Blockers
No verified Printify product/variant geometry, supplier templates, real subject rights/consent, font rights, physical samples or reviewer signoffs. The eight prototypes are not certified, not ready to sell, and not substitutes for the 60-case AI-engine certification. Keep STOP ALL and external lock ON; automation OFF. No live API calls or spending.
