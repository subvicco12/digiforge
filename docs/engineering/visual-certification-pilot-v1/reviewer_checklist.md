# Independent reviewer checklist

For each case record reviewer identity, timestamp, source SHA-256, matte SHA-256, generated-art SHA-256, renderer/version, shop, case ID and decision.

- [ ] Rights and subject consent evidence authentic and applicable
- [ ] Source/matte provenance, hashes and dimensions consistent
- [ ] Correct subject and selected face(s), no unintended people/pets
- [ ] Ears, hair, fur, whiskers and facial outline preserved
- [ ] No obvious holes, halos, background fragments or unacceptable boundary contact
- [ ] Light, dark and checkerboard views inspected at 100% and intended product scale
- [ ] FACE_REPEAT placement, repeat seams and preview/final consistency inspected
- [ ] QA metric report reviewed; exceptions explicitly explained
- [ ] Supplier-specific print geometry and sample evidence separately checked when applicable
- [ ] Decision: APPROVE / REVISE / REJECT / BLOCKED (do not default to APPROVE)
- [ ] Annotated defects and immutable reviewer evidence recorded
- [ ] Independent second reviewer decision recorded when required

**No self-approval.** New source, mask or output hash invalidates stale approvals. APPROVE is visual pilot acceptance only, never automatic listing/production certification.
