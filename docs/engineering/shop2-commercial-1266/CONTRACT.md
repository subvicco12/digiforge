# Optional held commercial worksheet v1

CommercialWorksheet::assess(array $input,array $expectedBinding):array is a pure, bounded, no-I/O review calculation. The compiler supplies expected shop/environment/fixture/product/artwork/template/provider/variant identity from its resolved design and package template. Input binding must match exactly; checksums and source classifications never grant authority.

Input schema DF_SHOP2_COMMERCIAL_WORKSHEET_1: immutable as_of UTC; USD integer cents for item price, buyer shipping, buyer tax and nine cost components; integer basis points for transaction, processing, ads, refund reserve and item discount; proposed target margin. Every known value references one retained HTTPS source hash with classification and observation/expiry dates. Missing amounts stay null. Unknown extra fields, booleans/floats/negative money, substituted bindings and future observations deny. Historical observations and assumptions remain labeled; source verification is never inferred from submitted metadata.

Revenue excludes collected buyer tax. Transaction, ads and refund reserve use discounted item plus buyer shipping; processing uses that gross plus buyer tax and an explicitly converted USD fixed processing charge. Supplier shipping is a cost; buyer shipping is revenue. One all-in conversion/withdrawal amount is permitted, preventing a second implicit Etsy/Payoneer conversion charge. Merchant tax cost is separate from collected buyer tax. Each modeled percentage fee rounds up to cents. A bounded 10,000-cent rounding-residue search finds the minimum proposed list-item price meeting the chosen pretax-gross margin under the same discount/fee assumptions; no owner-approved minimum is issued.

Null costs/rates and expired sources used by known input values prevent modeled margin/minimum-price results. Known policy/historical assumptions may support conditional arithmetic, never actual account profit. Freshness is assessed at the explicitly sealed as_of time; valid_until and source freshness blockers remain visible, and every artifact requires refreshing/review before commercial use. No live currentness is asserted by a static export. Changing source, variant, artwork or any assumption changes the package seal and requires a new decision. W03 proof/business binding and held-only export semantics remain unchanged. All provider qualification and commercial approvals remain false/null.

When detailed evidence is present, legacy economics must retain only currency and the SAME item price; all seven legacy cost fields must be null. The compiler derives display/handoff fields from the worksheet, preserving item-only Etsy draft price and a separate buyer_shipping amount. Legacy inputs without commercial_worksheet retain byte-identical output. Source HTTPS credentials/userinfo and credential/signature query fields are rejected. No source URL is fetched by the calculator.
