# DigiForge v1.0.91 Release Lineage

DigiForge 1.0.91 establishes a distinct release identity for the certified recovery-control-plane changes developed after the original 1.0.90 release.

- Database schema remains 23.
- The historical v1.0.90 recovery plan, backup binding, restored staging evidence, and external-operation evidence remain immutable and must not be rewritten as v1.0.91 evidence.
- v1.0.91 does not grant production activation, commerce execution, Etsy publish, POD production, or recovery-drill acceptance authority.
- STOP ALL and existing fail-closed controls remain authoritative.
- Release certification requires the exact-head Engineering & Safety Audit and its reproducible package artifact.
