# DigiForge v0.13.3

## Scope
U3 Product Factory repair hardening for Product #3 and future repair runs.

## Changes
- Repair production plans use run-derived plan identity while preserving stable product/version identity.
- Repair customer-package ZIPs use deterministic run-scoped filenames to prevent immutable stale ZIP reuse.
- Repair customer-package asset specs use a deterministic repair variant, avoiding the existing product-version package identity collision.
- Gate 2 Approval Inbox exposes semantic QA evidence and remains human-controlled.
- Initial U3 production behavior remains unchanged.
- Database schema remains version 13.

## Safety
No Etsy publishing, Etsy draft creation, Printify, Gelato, order automation, GST automation, or other external fulfillment action is enabled by this release. Product Approval remains a separate human gate.
