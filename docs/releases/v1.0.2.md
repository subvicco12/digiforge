# DigiForge 1.0.2 — Production Candidate

## Scope
Integrated operator-finish release candidate based on certified main commit `0145aa1518d4798fe2d5ff4bb2dc24118ab9804d`.

## Operator workflow
- Gate 1: Opportunity Approval.
- Automated Product Factory and QA progression.
- Gate 2: Product Approval.
- Automated listing-package and validation progression.
- Gate 3: Listing / Publish Approval.
- Dashboard surfaces opportunity approvals, product approvals and publish-ready listings.

## Safety boundary
This release does not authorize external execution. Etsy draft/publish, Printify, Gelato, orders/fulfillment and GST/tax automation remain governed by the existing fail-closed controls. No candidate is auto-approved by this release.

## Packaging
Build with `bin/package-plugin.sh`. The package script creates `digiforge.zip`, creates its SHA-256 manifest and verifies the checksum before completion. Development/test surfaces are export-ignored.

## Production smoke gate
Live smoke execution remains blocked until the prerequisites in `docs/testing/P5_PRODUCTION_SMOKE_TEST_PLAN.md` are truthfully satisfied, including a verified production database backup and recovery readiness.
