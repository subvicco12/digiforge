# DigiForge v0.13.4

## U3 repair asset-spec identity hardening

This release fixes the repair-cycle asset-spec collision exposed by Product #3 Action #25.

- Repair production plans retain deterministic run-specific identities.
- Every generated product and marketing asset specification now receives the deterministic repair variant for that repair run.
- The customer package uses the same repair variant and run-specific ZIP filename.
- Replaying the exact same repair run remains idempotent.
- Initial/non-repair asset identities remain unchanged.
- Product and product-version identity remain stable across repair cycles.
- Historical specifications, revisions, and QA evidence are preserved.
- Database schema remains version 13; no migration is required.
- Etsy draft/publish, Printify, Gelato, order automation, and GST automation are not activated by this release.

Gate 2 Product Approval remains a human approval boundary.
