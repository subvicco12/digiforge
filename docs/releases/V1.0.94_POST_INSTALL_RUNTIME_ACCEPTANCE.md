# DigiForge v1.0.94 Post-Install Runtime Acceptance

This checklist records runtime evidence after installing the exact certified inner `digiforge.zip`. It does not authorize external execution and it does not convert missing evidence into PASS.

## Certified source binding

Record the successful exact-head Engineering & Safety Audit, audited candidate SHA, GitHub artifact identifier, outer digest, inner package checksum and manifest binding before installation. Missing or mismatched certification evidence is UNAVAILABLE, not PASS.

## Fail-closed decision

Runtime acceptance is PASS only when every required runtime item above is directly evidenced. A healthy install does not grant Etsy publish, POD production, fulfillment dispatch, refund, money movement, tax/GST filing, retry, recovery execution, or any other consequential external authority.

The separately authorized destructive recovery restore applies to DigiForge staging only and is not performed by installation or supersession. A fresh recovery operation still requires its own verified artifact and backup bindings, plan, and governed execution path. Production must not be touched.
