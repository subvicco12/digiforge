The controller also released reservations on uncertain callback exceptions/errors, allowing duplicate resubmission. For future u3_build_product_<candidate> calls only, bound audit receipts now carry SHA256(stored key), SHA256(client key), operation and terminal response digest (plus returned run-key digest where available).
