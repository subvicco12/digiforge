## Storage decision

AssetStorage confines real paths but does not resolve shop ownership and relies
on .htaccess for direct-web denial. LocalAssetProducer accepts a numeric product
version rather than an approved shop/artwork binding. Neither is sufficient by
itself to introduce a new public-file reference boundary.

Reuse the existing durable OpportunityDesignRepository storage instead. The new
explicit reference entry reads current authenticated shop-scoped immutable artwork,
verifies its original record SHA256, approval and SVG checksum, then emits a compact
reference instead of inline bytes. No file write, public URL, symlink following,
remote fetch, rasterization or increase to the existing inline/package limit.
The existing upstream SVG/record bounds still apply. Every stored package read,
approval/export and artwork retrieval must resolve current evidence again.

STOP ALL ON; external lock ON; automation OFF; Manual orders; RELEASE HOLD.
Technical fixture artwork and synthetic test evidence are not commercial approval.
