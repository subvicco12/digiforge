## Working demonstration instructions

These steps apply when this candidate is loaded in an authorized development/test WordPress instance. No live-site deployment occurred.

1. Sign in with `manage_digiforge`, `manage_digiforge_research`, and `manage_digiforge_pod`. Open the existing page containing `[digiforge_admin_portal]` with `?df_view=research&df_shop=personalized_pod#df-commercial-research`.
2. Under **Capture or revise source evidence**, enter a title, mug/poster family, actual source URLs, personally observed excerpts, exact UTC capture dates and provenance. Add multiple sources as needed; a blank category is unknown. Save. The redirect opens the immutable research hash. Repeating identical research returns the same candidate.
3. Copy the source-grounded request to an already authorized assistant, or author a matching JSON response manually. Paste exactly `scores` and three `concepts`; the request contains the response field contract. For an AI import select the AI provenance option and supply provider/model/response reference/generation time. These declarations remain unverified. The repository fixture shows a fully synthetic schema example; do not submit it as market validation.
4. Inspect the scores, source references, three compositions, palettes, personalization plans and originality notes. Select one direction. Copy its specific design prompt. The page explicitly states that this is not artwork.
5. Create original artwork in an authorized tool. Paste actual editable SVG, exact pixel dimensions and native layer names. Enter rights and review notes; explicitly confirm originality, licensing, safe area and mockup checks. Save the new artwork version. The immutable artwork hash is the editable asset reference.
6. Inspect that exact SVG/evidence/version. Record APPROVE or REJECT with an explicit human rationale. Verify the confirmed Day1 approval state, actor and exact evidence hash. If decision confirmation fails, inspect the returned review-intent hash before any retry.
7. Use **Start research revision** or edit the prefilled source evidence form to revise, preserving parent history and old decisions. Use **Reuse for product family** to adapt concepts to a new mug/poster while requiring a new selection and artwork review. History links open exact previous versions.

Local automated demonstration: run the `CommercialResearchWorkflowTest::testPortalResearchToApprovedAssetKeepsLaneBEnvelope` integration test.
