`PetCutoutCompositor` implements actual pixel processing with packed RGBA/matte strings and bounded scanlines/counters, not per-pixel objects. It consumes the existing verified prepared PNG and a separately supplied, fully decoded8-bit single-channel grayscale PNG execution matte with exactly matching dimensions. RGB/RGBA/16-bit/profile-bearing, incomplete or malformed mattes are rejected rather than converted. The original source and preparation receipt are unchanged.

For every pixel, effective alpha is floor((As*M+127)/255). Retain source RGB if effective alpha is positive and canonicalize alpha-zero RGBA to zero. Require explicit half-open integer crop, canvas and placement rectangles. Reject crop loss of any positive effective support, empty support, rectangle overflow, invalid alignment and unknown options. Only factors1,2,4 use the exact supplied premultiplied integer-box sums and half-up division. There is no segmentation, enlargement, mirroring, rotation, arbitrary scale, text, added background or invented anatomy.
