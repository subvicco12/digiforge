=== DigiForge Printify API ===
Requires at least: 7.1
Requires PHP: 8.3
Stable tag: 0.1.0

This passive engineering candidate exposes an in-process diagnostic status.
It declares no provider capabilities and enables no provider execution.
It is independent of DigiForge Core and Printify Companion at load time.
It creates no routes, scheduled jobs, credential store, options, or tables.

The release hold remains active. Package verification covers offline source
identity and bootstrap only. Installation and live acceptance are separate.
